## ما هي Arabic spot؟

**Arabic spot** مهارة (Agent Skill) تجمع خمسة تخصّصات أدبية في مكان واحد. تمنح وكيلك تعليمات منهجية للكتابة والتحليل والتحرير، بدل الاعتماد على إجابات عامة غير مترابطة.

| المجال | ماذا تقدّم؟ |
|:--|:--|
| **الشعر** | تأليف أبيات أصلية، شرح القصائد، النقد والمراجعة. |
| **العَروض والقافية** | تحليل البحور والتفعيلات، التنبّه للكسور، فحص الروي. |
| **البلاغة** | تحليل التشبيه والاستعارة والكناية، وعلمَي المعاني والبديع. |
| **الفصاحة** | تحسين الأسلوب، ضبط السياق، وتصحيح التراكيب الركيكة. |
| **الإلقاء** | اقتراح الوقفات والتنغيم وتوزيع الأداء على الأبيات. |

> [!IMPORTANT]
> المهارة **تعليمات ومراجع**، وليست نموذجًا مستقلاً أو ضمانًا لصحة الوزن بنسبة 100%. التقطيع البرمجي اختياري ويحتاج مكتبة `pyarud` منفصلة. لا تدّعي المهارة توثيق بيت أو تحليله آليًا دون فحص فعلي.

## ابدأ في أقل من دقيقة

**التثبيت باستخدام Skills CLI** (بعد نشر المستودع):

```bash
npx skills add https://github.com/cj0rm/arabic-spot --skill arabic-spot -a codex
```

أو ثبّت من مجلد المشروع المحلي:

```bash
# macOS / Linux
bash scripts/install.sh

# Windows PowerShell
.\scripts\install.ps1
```

**الاستخدام في Codex:**

```text
$arabic-spot اكتب لي ستة أبيات عن عُمان، مع مراجعة الوزن والقافية.
```

يمكن أن يختار Codex المهارة تلقائيًا إذا كان الطلب متعلقًا بمحتواها. للمزيد: [دليل التثبيت](docs/INSTALLATION.md).

## أمثلة حقيقية للاستخدام

```text
$arabic-spot حلّل هذا البيت من حيث البحر والروي والصورة البلاغية.

$arabic-spot أكمل القصيدة مع الحفاظ على المعنى والقافية، ثم نبّهني إلى أي كسر محتمل.

$arabic-spot أعد صياغة هذا النص بلغة عربية فصيحة وواضحة دون مبالغة لفظية.

$arabic-spot جهّز لي خطة إلقاء لقصيدة في حفل رسمي وحدّد الوقفات والتنغيم.
```

## الجودة والحدود

- يفرّق بين الشعر العمودي وشعر التفعيلة وقصيدة النثر والشعر الشعبي.
- لا ينسب بيتًا لشاعر أو مصدر دون تحقق.
- يفرّق بين التحليل البلاغي المؤكد والتأويل المحتمل.
- لا يصف الوزن بأنه مفحوص آليًا دون تشغيل محرك التقطيع فعلًا.
- لا يحتاج إلى خادم أو مفتاح API من أجل العمل بوصفه مهارة تعليمات.
- يضم فحصًا بنيويًا يمكن تشغيله محليًا: `python3 scripts/validate.py`.
