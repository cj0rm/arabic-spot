## ما هي Arabic spot؟

**Arabic spot** مهارة أدبية موحّدة تجمع خمسة مجالات مترابطة في تجربة واحدة. تساعدك على كتابة الشعر العربي وشرحه، ومراجعة الأوزان والقوافي، وتحليل الصور البلاغية، وتحسين الأسلوب، والاستعداد للإلقاء.

بدل التنقّل بين أدوات متفرقة، اطلب ما تحتاج إليه باللغة العربية، وستختار المهارة المنهج المناسب للمهمة.

## ماذا تقدّم؟

| المجال | الإمكانات |
|:--|:--|
| **الشعر والقصائد** | تأليف نصوص شعرية أصلية، وشرح الأبيات، ومراجعة الصور والمعاني. |
| **العَروض والقافية** | دراسة البحور والتفعيلات، وتحديد الروي، والتنبيه إلى الكسور المحتملة. |
| **البلاغة العربية** | تحليل التشبيه والاستعارة والكناية، وألوان المعاني والبديع. |
| **الفصاحة والكتابة** | صقل الأسلوب، وتحسين التراكيب، وتحرير النصوص العربية بوضوح وسلاسة. |
| **فنّ الإلقاء** | إعداد الوقفات والتنغيم والإيقاع بما يناسب معنى القصيدة ومقامها. |

## ابدأ في أقل من دقيقة

ثبّت المهارة باستخدام Skills CLI:

```bash
npx skills add https://github.com/cj0rm/arabic-spot --skill arabic-spot -a codex
```

ثم استخدمها داخل الوكيل:

```text
$arabic-spot اكتب لي ستة أبيات عن عُمان، ثم راجع البحر والقافية ووضّح أي موضع غير مؤكّد.
```

للتثبيت اليدوي على نظامك، راجع [دليل التثبيت](docs/INSTALLATION.md).

## أمثلة للاستخدام

**تأليف قصيدة:**

```text
$arabic-spot اكتب قصيدة فصيحة عن عُمان بمطلع قوي وقافية موحّدة.
```

**تحليل بيت شعري:**

```text
$arabic-spot حلّل البيت التالي من حيث المعنى والصورة البلاغية والوزن والروي.
```

**مراجعة قصيدة:**

```text
$arabic-spot راجع هذه القصيدة وحسّن الأسلوب مع المحافظة على المعنى والقافية.
```

**تحرير النصوص العربية:**

```text
$arabic-spot أعد صياغة هذه الفقرة بلغة عربية فصيحة، طبيعية، ومناسبة لخطاب رسمي.
```

**الاستعداد للإلقاء:**

```text
$arabic-spot أعد لي خطة إلقاء لهذه القصيدة وحدّد الوقفات والتنغيم والمواضع المؤثرة.
```

## الدقة والموثوقية

تراعي المهارة الفروق بين الشعر العمودي وشعر التفعيلة وقصيدة النثر والشعر الشعبي، وتفصل بين التحليل المؤكد والتفسير المحتمل. وهي **تعليمات ومراجع أدبية** وليست ضمانًا لصحة كل نتيجة عروضية. التقطيع البرمجي اختياري ويحتاج إلى مكتبة مستقلة؛ ولا تُنسب الأبيات إلى أصحابها دون تحقق.
