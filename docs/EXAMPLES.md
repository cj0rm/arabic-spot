# أمثلة استخدام Arabic spot

## إنشاء قصيدة موزونة
```text
$arabic-spot اكتب ستة أبيات أصلية عن جمال عُمان على بحر تختاره مع قافية موحدة، ثم وضّح البحر وحدود الثقة في سلامة الوزن.
```

## تحليل بيت
```text
$arabic-spot حلّل هذا البيت، ثم اشرح معناه وصوره البلاغية والروي. ميّز التحليل المؤكد من المحتمل.
```

## إصلاح قافية
```text
$arabic-spot راجع هذه القصيدة؛ تحقق من القافية واقترح تعديلات قليلة تحافظ على المعنى ولا تدّعِ فحصًا آليًا دون تشغيل المحرك.
```

## صياغة عربية فصيحة
```text
$arabic-spot أعد كتابة هذه الفقرة بأسلوب عربي طبيعي وأنيق دون تغيير المعنى، واشرح أهم تصحيحين.
```

## إلقاء قصيدة
```text
$arabic-spot جهّز توجيهات إلقاء لهذا النص في أمسية شعرية: الوقفات، مواضع التشديد، السرعة، والتنغيم.
```

## دراسة البلاغة
```text
$arabic-spot استخرج التشبيه والاستعارة والكناية والطباق من النص إن وجدت، واستشهد بالألفاظ ولا تتكلف تصنيفًا.
```
