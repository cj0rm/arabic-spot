# النشر | Publishing

## نشر المستودع
المستودع الرسمي: https://github.com/cj0rm/arabic-spot

تأكد من أن الفرع `main` يتضمن `SKILL.md` و`README.md` والمراجع والملفات القانونية. قبل أي إصدار:

```bash
python3 scripts/validate.py
```

يمكنك إنشاء إصدار GitHub Release مثل `v1.0.0` بعد مراجعة النصوص، ووضع `Arabic spot` عنوانًا.

## النشر على SpotEase
الصفحة المستقلة داخل `web/` لا تحتاج إطار عمل. يمكن استضافتها على `spotease.om/arabic-spot`، أو تحويلها إلى مكون React ضمن الموقع الحالي.

- انسخ `web/index.html` و`web/styles.css` إلى مسار الاستضافة.
- احتفظ بروابط المستودع وروابط التثبيت.
- لا تصف المهارة بأنها محرك عروض محقق بالكامل؛ التقطيع الآلي اختياري.
- أظهر المصدر والترخيص وإخلاء الارتباط بالمشاريع الأصلية.
- ضع رابط المهارة في قسم مشاريع SpotEase أو صفحة أدوات المطورين.

## وصف مقترح للموقع
**Arabic spot: من المعنى إلى الوزن، ومن البلاغة إلى الإلقاء.** مهارة مفتوحة المصدر تضيف إلى مساعدك منظومة متكاملة لتأليف الشعر العربي وشرحه، ودراسة العروض والقافية والبلاغة، وتحسين الأسلوب العربي وإعداد الإلقاء.
